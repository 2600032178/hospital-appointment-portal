# CityCare Hospital - Patient Appointment Website

Lab Experiment 2: refactor a non-semantic hospital web page into engineering-grade,
accessible HTML.

- `main` branch: the original (legacy) page built from `div` elements.
- `feature/semantic-accessible-refactor`: the refactored page, accessible appointment
  form, and before-and-after accessibility audit.

Open `index.html` in a browser to view the page. No build step is needed.
